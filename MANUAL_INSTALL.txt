================================================================================
MANUAL INSTALLATION GUIDE - If setup.py Fails
================================================================================

FOR YOUR CURRENT LAPTOP SETUP (Windows):
========================================

Step 1: Navigate to project
----------------------------
cd C:\Users\Admin\Desktop\Buyo-Leaf-Classifier


Step 2: Create Virtual Environment
-----------------------------------
"C:/Program Files/Python311/python.exe" -m venv venv


Step 3: Activate Virtual Environment
------------------------------------
venv\Scripts\activate

(You should see (venv) in your prompt)


Step 4: Upgrade pip
-------------------
python -m pip install --upgrade pip


Step 5: Install Core Dependencies
----------------------------------
pip install -r laptop_client\requirements.txt


Step 6: Install PyTorch with CUDA
----------------------------------
Check your CUDA version first:
    nvidia-smi

Then install PyTorch:

For CUDA 11.8:
    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118

For CUDA 12.1:
    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

For CPU only (slower):
    pip install torch torchvision


Step 7: Verify Installation
----------------------------
python -c "import torch; print('PyTorch:', torch.__version__)"
python -c "import torch; print('CUDA available:', torch.cuda.is_available())"
python -c "import cv2; print('OpenCV:', cv2.__version__)"
python -c "import requests; print('Requests:', requests.__version__)"


Step 8: Run the Application
----------------------------
Make sure you're in the project root:
    cd C:\Users\Admin\Desktop\Buyo-Leaf-Classifier

Make sure buyo_best.pth exists in project root:
    dir buyo_best.pth

Run the GUI:
    python laptop_client\laptop_client_gui.py

================================================================================
TROUBLESHOOTING COMMON ISSUES
================================================================================

Issue: "pip install" is slow or hangs
--------------------------------------
Solution: Press Ctrl+C and try again
Or use: pip install --timeout 300 <package>


Issue: "Could not find a version that satisfies the requirement"
----------------------------------------------------------------
Solution: Your internet connection or pip index might have issues
Try: pip install --index-url https://pypi.org/simple <package>


Issue: "Access is denied" when installing
-----------------------------------------
Solution: Make sure antivirus is not blocking Python
Or run Command Prompt as Administrator


Issue: CUDA version mismatch
-----------------------------
Check CUDA version: nvidia-smi
Check PyTorch CUDA support: https://pytorch.org/get-started/locally/
Install matching version


Issue: "No module named 'torch'" after install
----------------------------------------------
Make sure you're in the venv:
    venv\Scripts\activate
Check where it's installed:
    pip show torch

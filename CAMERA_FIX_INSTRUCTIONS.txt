RASPBERRY PI CAMERA 3 (imx708) FIX - QUICK SOLUTION
================================================================================

PROBLEM IDENTIFIED:
-------------------
Your Raspberry Pi Camera 3 (imx708) is working fine in Firefox because the 
system has picamera2 installed. However, the Python virtual environment (venv)
cannot access it because it was created WITHOUT system-site-packages access.

The server code shows:
  ✗ Picamera2 not available: No module named 'picamera2'

This is why the camera preview shows black screen.


SOLUTION:
---------
You need to recreate the venv with access to system packages (picamera2).


OPTION 1: Automated Fix (RECOMMENDED)
--------------------------------------
Run this one command on your Raspberry Pi:

    bash fix_picamera2.sh

This script will:
1. Verify picamera2 is installed as system package
2. Delete old venv
3. Create new venv with --system-site-packages flag
4. Reinstall all project packages
5. Test that picamera2 is accessible
6. Show detected cameras

Takes ~2 minutes.


OPTION 2: Manual Fix
---------------------
If you prefer to do it manually:

1. Stop the server if running (close GUI or press Ctrl+C)

2. Delete the old virtual environment:
   
   cd ~/Desktop/Buyo-Leaf-Classifier
   rm -rf venv

3. Install picamera2 system package if not already installed:
   
   sudo apt update
   sudo apt install python3-picamera2

4. Create NEW venv with system packages access:
   
   python3 -m venv venv --system-site-packages

5. Activate venv and install packages:
   
   source venv/bin/activate
   pip install --upgrade pip
   pip install -r raspberry_pi_server/requirements.txt

6. Test picamera2 access:
   
   python3 -c "from picamera2 import Picamera2; print('SUCCESS!')"

7. Run the server:
   
   python3 raspberry_pi_server/pi_server_gui.py


VERIFICATION:
-------------
When you run the server, you should see in the terminal:

  ✓ Picamera2 library found
  🔍 Detecting available cameras...
  📸 Found 1 Pi Camera(s)
     Camera 0: {'Model': 'imx708', ...}
  🔄 Initializing Picamera2...
  ✓ Camera ready: (480, 640, 3)

And in the GUI:
  - Camera preview should show LIVE VIDEO (not black)
  - Camera status: "Camera: Pi Camera (imx708)" in GREEN


WHY THIS HAPPENED:
------------------
The original setup script created venv without --system-site-packages flag:
  
  python3 -m venv venv  ❌ (isolated from system packages)

Should have been:
  
  python3 -m venv venv --system-site-packages  ✓ (can access picamera2)

This has been fixed in the raspberry_pi_quick_setup.sh script for future setups.


AFTER THE FIX:
--------------
Your camera should work immediately. The server will:
1. Detect "Pi Camera (imx708)"
2. Show live video in preview
3. Stream video to laptop client at http://YOUR_PI_IP:5000/video_feed


TROUBLESHOOTING:
----------------
If camera still doesn't work after the fix:

1. Check camera cable is firmly connected to Raspberry Pi

2. Verify camera is enabled in raspi-config:
   
   sudo raspi-config
   → Interface Options → Camera → Enable

3. Test camera directly with libcamera:
   
   libcamera-hello

4. Reboot Raspberry Pi:
   
   sudo reboot

5. Check terminal output when running server for specific error messages
